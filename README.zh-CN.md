# PhotoPort 本机版

**把 Airtable 里的照片和附件下载下来，按货号、客户或记录分文件夹，并生成带图片预览的 Excel。**

[English](README.md) · [产品介绍与在线版报名](https://photoport-local.pages.dev/zh/) · [反馈问题](https://github.com/marlon-z/web-photoport/issues)

本机版免费开源。照片处理在你自己的电脑上完成，不需要注册 PhotoPort、绑定银行卡、购买 R2 或配置数据库。当前界面为中文。**在线版还没开放，报名不是付款。**

## 安装：先安装 Node，再启动程序

1. 到 [Node.js 官网](https://nodejs.org/en/download)安装 **Node.js 22 或更新版本**。
2. 下载 [最新版本源码 ZIP](https://github.com/marlon-z/web-photoport/releases/latest)，解压到自己的文件夹。
3. Windows 用户可以双击 `start-photoport.cmd`。它会检查 Node，首次安装项目依赖，然后启动程序。不会购买云服务。
4. 打开 **http://127.0.0.1:4180/app**。导出时保持启动窗口打开，结束后按 Ctrl+C。

也可以在包含 `package.json` 的目录打开终端运行：

```sh
npm ci
npm start
```

第一次安装和下载 Airtable 附件需要联网。使用本软件不需要 Python。安装后重新打开终端，才能识别新装的 Node。

## 先试一次，不用账号

点击“先试商品整理示例”，选择“客户 → 货号”，再点击“下载全部照片”。示例用生成的商品图，实际生成能解压的照片包和 Excel，不会访问你的 Airtable。

## 用自己的表格

**方式一：导入 CSV，设置最少。** 从 Airtable 网格视图导出一份新 CSV，保留附件列、商品货号和客户等需要的列，再导入本工具。CSV 中必须含附件下载地址；只有文件名的 CSV 无法下载照片。临时地址过期后需要重新导出。

**方式二：只读连接。** 在 [Airtable 官方凭证页面](https://airtable.com/create/tokens)创建只读凭证，权限只选 `data.records:read`、`schema.bases:read`，只允许目标资料库。点击“使用只读连接”，填表格地址和凭证。凭证只留在本机进程内存，关闭程序后需重新连接。本机版不提供网站账号版的一键授权。

接下来：

1. 预览表格，选择附件列和要导出的记录。
2. 选择按记录、货号、客户或两层文件夹整理；可以先看文件位置。
3. 下载完整 ZIP，或者只下载成功文件。失败项目会进入清单，支持重试。
4. ZIP 内有原文件、Excel 缩略图目录、离线图片目录、文件清单和所选原表数据。

原文件名尽量保留，不同文件同名时自动加序号。系统不允许的字符会替换，清单仍记录原名和所属记录。Excel 中是缩略图，原图在 `photos/` 里。CSV 没有原始记录编号时使用行编号；CSV 本来带的记录编号列会保留在原表数据中。

## 大小限制与中断恢复

- 每个文件最多 **20 MiB**，一批最多 **10 GiB、15,000 个附件**。
- 磁盘建议留出原始附件总大小 **3 倍以上**的空余空间。整批 10 GiB 可能需要超过 30 GiB。
- 程序重启后，重新连接原库或导入更新了链接的同一份 CSV，再点“继续上次任务”。CSV 要保持原有列、行顺序；核对通过的文件可以复用。
- CSV 链接无法自动续期；源数据删除、权限变化、接口额度用完时仍可能失败。
- 这是附件整理工具，不是完整 Airtable 备份，也不支持写回或双向同步。

## 私人资料在哪里

下载缓存、任务进度和记录信息保存在本机 `.runtime/`，可能包含私人资料。断开连接只清除内存凭证，不会删除这些文件。确认不再需要后，退出程序，再手动删除 `.runtime/`。

程序只监听本机地址。不要把本机版挂到公网、隧道或共享服务器，它没有为公开多人使用提供安全隔离。请勿在 GitHub 问题中上传真实 CSV、照片、凭证或 `.runtime/`。

本机工具不向维护者发送统计或用户资料。下载会访问 Airtable 和它的附件服务器。免费本机版关闭云上传入口，不调用支付。Airtable 自身套餐限制、你电脑的网络和磁盘成本仍适用。

## 常见问题

- **找不到 node/npm：**安装 Node 后重新打开终端。
- **4180 端口占用：**停止另一个本机版；或 PowerShell 输入 `$env:PORT='4181'; npm start`，再访问 4181。
- **CSV 里没有照片：**检查是否导出了附件列、是否含有效的官方下载地址。
- **只显示部分文件：**查看失败清单和大小限制；可以缩小选择范围重新导出。
- **想反馈：**到 GitHub Issues 描述步骤和错误，用虚构示例，不贴私人数据。

开发者测试需要 Node；部分 ZIP 独立核验测试额外需要 Python 3。运行 `npm test`、`npm run test:site`、`npm run audit:release`。

维护者可以查看[上线后的中文操作说明](docs/OPERATIONS.zh-CN.md)，了解流量、私有报名数据、免费额度和暂停报名的方法。
