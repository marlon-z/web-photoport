Where can I get a read-only token?

Open the Airtable token page and select data.records:read and schema.bases:read scopes, limited to this base. A token lets PhotoPort refresh expiring download links and read linked record names. One-click account authorization is not available in this edition.

Supported files, storage and usage
Up to 15,000 attachments, 20 MiB (about 20.97 MB) per file and 10 GiB (about 10.74 GB) per batch. Supports common images, documents, audio and video. Images get thumbnails; other attachments keep their original files.
CSV files must contain valid Airtable attachment links. Files stay on this computer by default. Local URLs are not lasting website image URLs. You can switch pages while the program runs. Closing the program interrupts processing; reopen it to resume.
This service accepts local connections only. Tokens stay in memory. Disconnecting does not delete downloaded files. There is no payment or automatic purchase feature.
