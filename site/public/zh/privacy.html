资料保存说明

更新日期：2026年10月22日。由 marlon-z / PhotoPort 维护。

本机工具与网站互相独立

本机工具在你自己的电脑处理 Airtable 附件，不把照片、表格或凭证发送给维护者。缓存和任务信息保存在 .runtime，退出程序后可由你删除。本机工具不收集使用统计，也不向介绍网站发送导出结果。

报名保存什么

仅保存你填写的邮箱、用途、资料大小、价格意向、可选需求和同意时间，用于 PhotoPort 开放通知及需求反馈联系。资料存放在维护者账号下的私有 Cloudflare D1 数据库，不公开、不出售。不要填写照片、密码、访问密钥或敏感个人资料。报名完全自愿，不开通订阅、不扣费。邮箱暂未验证，系统不会自动发送邮件。

删除报名

成功提交后会显示本次报名的专属删除链接，请保存。打开链接并确认即可删除这一条报名，无需公开邮箱。重复提交会产生独立记录，需要使用各自的删除链接。维护者会在验证阶段结束时检查并清理不再需要的报名。暂不承诺上线日期。

访问统计

网站可使用免费的 Cloudflare Web Analytics 查看汇总访问情况；GitHub 记录仓库和下载访问。本机工具不包含这些统计。报名接口为防滥用短暂保存 IP 与日期组合的散列值，不保存原始 IP；过期限制在后续请求时清理。Cloudflare 和 GitHub 按各自政策处理连接数据。

联系维护者

公开联系入口是 GitHub 个人主页。不要在公开 Issue 留下邮箱、密钥或个人资料。安全问题请使用仓库的私人漏洞报告入口。完整技术说明见资料处理说明。

PhotoPort 是独立工具，与 Airtable 无隶属关系。
